Introduction


BlowUp is a low friction markup language with an almost WYSIWYG plain-text formatting syntax for the most common situations writers encounter, and a set of extensions with a coherent JSON-based data model for the less common ones. Inspiration for its design has been taken from AsciiDoc, DocBook, LaTeX, Markdown, MathML, Plain Old Documentation, reStructuredText, Scalable Vector Graphics, Scribe, TeX, Texinfo and Troff.

This document is both a specification of the BlowUp language and a functional test for its parser.

Here is how code blocks can be written:

Hello!
This is a code block.
    Indentation is of course preserved.
    Inside a code block all transformations should be **disabled (you should not see this as bold)**.
    It must be possible to enter literals like [[http://www.google.com]] and <script>alert('You should not see this as an alert!');</script>.
Bye.

Backticks can be used for inline code like System.IO.File or for literals like [[http://www.google.com]] (you should not see this as a link) and <script>alert('You should not see this as an alert!');</script>.
